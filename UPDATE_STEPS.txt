HOW TO INSTALL THIS FOLDER OVER YOUR OLD ONE
=============================================
1. Close the running app (red Stop button in PyCharm, or Ctrl+C in the terminal).
2. In your project folder (e.g. ~/PycharmProjects/FitBuddy) delete the OLD code:
      app.py llm.py rag.py router.py safety.py trackers.py views.py debug_search.py
      and the folders: knowledge, eval, tests, docs
   Also delete these if they exist from a previous version: profile.py
   (Keep your venv folder.)
3. Copy EVERYTHING from this FitBuddy folder into your project folder.
   Always replace the whole set. Mixing old and new files causes errors like
   "module has no attribute ..." or "unexpected keyword argument".
   NEW in this version: recipes.py (plus userprofile.py, exercises.py, planner.py, meals.py, coach.py, docs/ from the last version)
4. Check:   ls knowledge | wc -l      -> should print 163
            python tests/test_logic.py     -> each should end with "0 failure(s)"
            python tests/test_planner.py
            python tests/test_meals.py
            python tests/test_app_logic.py
5. Run:     python app.py        <-- use THIS to get written answers from the language model
   The startup log should say: Search ready (embeddings, 164 passages)
   (Quick interface check without the model: FITBUDDY_NO_LLM=1 python app.py. Plans and meal plans
   work in this mode too, because they are built by code.)

If answers repeat or look wrong, run:  python debug_search.py "Meal ideas" meal
and paste the output.

SPEED NOTES (language model on a laptop CPU)
--------------------------------------------
- The model now loads in the background when the app starts. Replies appear immediately and get the model's
  friendly sentence once it is ready. The line under the header shows the model's status.
- The first start downloads about 3 GB once. Watch the terminal for progress. Later starts only load it (about a minute).
- A CPU writes roughly 3 to 8 words per second, so the model's sentence can take 10 to 30 seconds. This is normal.
- To go faster, try the smaller model:      FITBUDDY_MODEL=Qwen/Qwen2.5-0.5B-Instruct python app.py
- On an Apple Silicon Mac you can also try: FITBUDDY_DEVICE=mps python app.py   (if answers look garbled, remove it)
